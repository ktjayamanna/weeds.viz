Stack Details

Stack Pointers

RSP (Stack Pointer): Points to the top of the stack (current position)

RBP (Base Pointer): Points to the base of the current stack frame

Growth Direction

The stack grows downward toward lower memory addresses. Each function call pushes a new frame onto the stack.

Stack Frame Contents

Each frame contains:

  • Function parameters (if on stack)
  • Return address
  • Saved base pointer
  • Local variables
  • Saved registers
